# 집필 스타일 가이드

기후·환경 주간 브리핑의 모든 호는 이 문서를 따른다. 집필(`writer`)과 검수(`reviewer`)
에이전트가 같은 기준을 쓰도록 판단이 갈릴 만한 지점을 구체적으로 적는다.
템플릿은 `issues/_template/index.qmd`, 렌더링 견본은 `issues/_sample/index.qmd`에 있다.

## 1. 독자와 목소리

- **독자**: 기후·환경에 관심은 있지만 전문가는 아닌 사람. 연구자, 공무원, 기자,
  교사, 학생, 관심 있는 시민. 용어를 알면 좋지만 모른다고 읽기를 멈추지 않게 쓴다.
- **목소리**: 차분하고 정확하게. 경고하거나 설득하려 하지 않고, 무엇이 일어났고
  그것이 긴 흐름에서 어떤 의미인지 보여 준다. 판단은 독자에게 맡긴다.
- 좋은 소식과 나쁜 소식을 같은 무게로 다룬다. 진전이 있으면 진전이라고 쓴다.

## 2. 문체

- 본문은 **해라체**(“~했다”, “~이다”)로 쓴다. 사이트 소개 등 이슈 밖 페이지는 합니다체.
- 한 문장에는 한 가지 사실만. 50자를 넘으면 나눌 수 있는지 본다.
- 주체를 밝힌다. “~로 나타났다”보다 “WMO는 ~라고 밝혔다”.
- 능동형을 기본으로 쓴다. “~가 발표되었다”보다 “~가 발표했다”.
- 번역 투를 피한다. “~에 대한”, “~을 통해”, “~에 있어서”가 반복되면 고친다.
- 외래어는 국립국어원 표기를 따르되, 기관·제도의 공식 한국어 명칭이 있으면 그것을 쓴다.

## 3. 분량과 구성

| 요소 | 기준 |
| --- | --- |
| 호 제목(`title`) | 가장 큰 이슈 하나를 한 문장으로. 40자 이내. 물음표·느낌표 쓰지 않음 |
| 설명(`description`) | 세 줄 요약 첫 줄을 다듬어 1~2문장. 목록과 링크 미리보기에 나옴 |
| 세 줄 요약 | 정확히 3줄. 각 50자 이내. 이슈 5개 중 가장 중요한 3개 |
| 이슈 수 | 글로벌 3 + 국내 2 (국내 소식이 약한 주는 4 + 1) |
| 이슈 제목(`###`) | 무엇이 일어났는지 한 문장. 30자 이내. 발언 인용은 큰따옴표 |
| 이슈 본문 | “무슨 일이 있었나” 2~3문단, 400~700자 |
| 긴 흐름에서 보면 | 장기 자료나 배경 연구가 있을 때만. 2~4문장 |
| 왜 중요한가 | 2~3문장. 정책·산업·생활에 미치는 의미 |
| 더 볼 것 | 원문 링크 1~3개 |
| 이번 주의 연구 | 0~2편. 편당 2~4문장 |
| 숫자로 보는 이번 주 | 큰 숫자 1개 + 차트 1~2개 |

블록을 쓰는 방법(마크다운 문법)은 템플릿에 있다. 비어 있는 블록은 남기지 말고 지운다.
“후속 보도”, “정정”, “이번 주의 연구”는 해당 내용이 있을 때만 둔다.

## 4. 출처 표기

### 어디에 다는가

출처를 **참고한 문장에만** 단다. 모든 문장에 다는 것이 아니다.

| 단다 | 달지 않는다 |
| --- | --- |
| 출처에서 가져온 사실 (누가, 언제, 무엇을) | 일반적인 배경 설명 (“온실가스는 열을 가둔다”) |
| 수치 (모든 숫자는 어딘가에서 왔다) | 용어 풀이 |
| 연구 결과, 모델 전망 | 문단 연결, 요약, 정리 |
| 발언과 직접 인용 | 필자의 해석과 평가 |
| 기관의 평가나 전망 | 이미 같은 문단에서 출처를 단 내용을 다시 받는 문장 |

판단이 애매하면: **그 문장이 틀렸을 때 독자가 확인할 곳이 필요한가?** 필요하면 단다.
일반 설명처럼 보여도 특정 수치나 최신 연구 결과를 담고 있으면 단다.

### 같은 출처가 이어질 때

한 문단에서 같은 출처를 잇달아 참고하면 **처음 한 번만** 단다. 다른 출처가 끼어든
뒤 다시 참고하면 다시 단다. 문단이 바뀌면 다시 단다.

### 문법

- 본문에서는 `[@id]`로 인용한다. 문장 끝, 마침표 앞에 붙인다: `밝혔다[@g-01].`
- 여러 출처는 `[@g-01; @g-02]`.
- 출처는 같은 폴더의 `references.json`(CSL JSON)에 넣는다. 번호와 출처 목록은 자동으로 만들어진다.
- id는 파이프라인의 출처 id를 그대로 쓴다.

| 접두어 | 뜻 |
| --- | --- |
| `g-` | 글로벌 리서치 |
| `k-` | 국내 리서치 |
| `a-` | 학술 리서치 (논문·보고서) |
| `b-` | 자료 보강 단계의 배경 자료 |
| `s-` | 장기 연속자료 |

### 출처의 주장과 필자의 해석을 구분한다

| 출처의 주장 (출처를 단다) | 필자의 해석 (출처를 달지 않는다) |
| --- | --- |
| ~라고 밝혔다 / 발표했다 / 분석했다 | ~로 볼 수 있다 |
| ~로 추정했다 / 전망했다 | ~라는 점이 눈여겨볼 대목이다 |
| 보고서에 따르면 ~ | ~할 것으로 보인다 |

필자의 해석을 출처가 말한 것처럼 쓰지 않는다. 출처가 말한 것을 출처 없이 단정하지 않는다.

## 5. 숫자와 단위

- **기준을 함께 쓴다.** 편차는 기준 기간을, 증감은 비교 대상을 밝힌다.
  - ○ “산업화 이전(1850~1900년) 평균보다 1.5℃ 높다”
  - ○ “1991~2020년 평균보다 0.6℃ 높다”
  - × “1.5℃ 상승했다” (무엇보다?)
- **출처의 정밀도를 넘지 않는다.** 출처가 1.5라고 했으면 1.50으로 쓰지 않는다.
- 퍼센트(%)와 퍼센트포인트(%p)를 구분한다.
- 큰 수는 만 단위로 끊는다: “3억 7,400만 톤”. 단위가 섞이면 원 단위를 괄호로 덧붙인다.
- 단위 표기: ℃, ppm, mm, km², GW, TWh, tCO₂eq(이산화탄소환산톤). 숫자와 단위는 붙여 쓴다(“1.5℃”, “420ppm”). 한글 단위는 띄운다(“3억 톤”).
- 날짜는 “10월 21일”, 연도가 다르면 “2025년 10월 21일”. 기간은 “1991~2020년”(본문), 캡션에서는 “1991–2020”.
- “사상 최고”, “관측 이래 최고”는 출처가 그렇게 말했을 때만, 관측 시작 연도와 함께 쓴다.

## 6. 용어

처음 나올 때 풀어 쓰고, 그다음부터 줄여 쓴다.

| 처음 | 이후 |
| --- | --- |
| 기후변화에 관한 정부 간 협의체(IPCC) | IPCC |
| 세계기상기구(WMO) | WMO |
| 유엔기후변화협약 당사국총회(COP30) | COP30 |
| 국가 온실가스 감축목표(NDC) | NDC |
| 이산화탄소(CO₂) | CO₂ |
| 엘니뇨·남방진동(ENSO) | ENSO |

- “지구온난화”와 “기후변화”를 구분해 쓴다. 기온 상승 자체는 온난화, 그로 인한 기후계 전체의 변화는 기후변화.
- “기후위기”는 기관이나 법령의 공식 명칭일 때만 쓴다(예: 「기후위기 대응을 위한 탄소중립·녹색성장 기본법」).
- 정부 부처는 발행 시점의 공식 명칭을 쓴다. 조직 개편 전 자료를 인용하면 당시 명칭을 쓴다.

## 7. 학술 자료

- 논문은 본문에 **저자, 학술지, 연도**를 자연스럽게 밝힌다: “Nature Climate Change에 실린 Kim 등의 연구는…”. 저자가 셋 이상이면 “첫 저자 등”.
- 원 논문을 찾았다면 언론 보도가 아니라 원 논문을 인용한다.
- **프리프린트**(동료심사 전)는 본문에 “동료심사를 거치지 않은 연구”라고 밝히고, “이번 주의 연구” 카드에 `[동료심사 전]{.preprint}` 배지를 단다.
- 단일 연구의 결과를 학계의 합의처럼 쓰지 않는다.

| 쓰지 않는다 | 쓴다 |
| --- | --- |
| ~임이 밝혀졌다 / 증명됐다 | ~라는 연구 결과가 나왔다 |
| 과학자들은 ~라고 말한다 | ○○ 연구진은 ~라고 분석했다 |
| ~하게 된다 | ~할 수 있다고 전망했다 (조건과 시나리오를 함께) |

- 모델 전망은 시나리오(예: SSP2-4.5)와 기간을 함께 쓴다.
- 연구의 한계(표본, 지역, 기간)를 출처가 밝혔다면 한 문장으로 옮긴다.

## 8. 장기 자료와 차트

- 차트는 `lib/briefplot.py`의 함수로만 그린다. 색, 글꼴, 축, 툴팁, 라이트/다크 대응이 들어 있다.
  - `line()`: 장기 시계열 1개. 마지막 값이 자동으로 표기된다.
  - `anomaly_bars()`: 기준값 대비 편차. 0보다 크면 붉은색, 작으면 푸른색.
- 차트 셀에는 `#| renderings: [light, dark]`와 `#| fig-alt:`(차트가 보여 주는 내용을 한 문장으로)를 반드시 단다.
- 한 차트에 한 가지 측정값. 단위가 다른 두 값을 한 차트에 겹치지 않는다(이중 축 금지).
- 차트 바로 아래에 `::: {.chart-source}` 캡션을 둔다. 형식:
  `자료: 기관, 데이터셋 이름(버전). 기간 YYYY–YYYY. YYYY년 M월 D일 수집.`
- 본문 수치와 차트 수치가 같은 자료, 같은 버전에서 나와야 한다.
- 장기 자료가 원천에서 개정되면 이미 발행한 호는 고치지 않는다. 캡션의 수집일로 당시 버전임을 알 수 있다.

## 9. 저작권

- 기사 본문을 옮기지 않는다. 요약하고 링크한다.
- 직접 인용은 **출처당 1문장 이내**, 큰따옴표로 표시한다.
- 원문의 문단 구성을 그대로 따라 바꿔 쓰지 않는다.
- 언론사, 기관, 학술지의 이미지·그림·표를 가져다 쓰지 않는다. 필요하면 공개 데이터로 직접 그린다.

## 10. 피하는 표현

| 피한다 | 이유 / 대안 |
| --- | --- |
| 전례 없는, 역대급, 충격적인 | 과장. 출처의 표현이면 인용으로 |
| 확정됐다, 사실로 드러났다 | 과학적 결과에는 “~로 분석됐다” |
| 처음으로 | 출처가 그렇게 말했을 때만 |
| 반드시, 틀림없이 | 전망에는 불확실성이 있다 |
| 늦기 전에 ~해야 한다 | 주장은 출처의 것으로 인용. 필자가 촉구하지 않는다 |
| 특정 정당·정치인에 대한 평가 | 정책 내용과 그 효과만 다룬다 |

## 11. 균형

- 한 호의 이슈가 한 분야(예: 기온 기록)로 쏠리지 않게 한다. 완화(감축), 적응, 생태, 정책, 과학을 고루 본다.
- 논쟁적인 정책은 찬반 양쪽의 근거를 출처와 함께 싣는다.
- 기업 발표는 홍보 자료임을 감안해 독립적인 출처로 교차 확인한다.

## 12. 정정

- 발행된 호는 지우지 않는다. 틀린 부분은 취소선으로 남기고 바로 뒤에 고친 내용과 정정 날짜를 적는다:
  `~~1.6℃~~ 1.5℃ (2026년 11월 3일 정정)`
- 다음 호 “정정” 절에 무엇을 왜 고쳤는지 한두 문장으로 알린다.
