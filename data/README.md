# data — 데이터 계층

데이터를 세 층으로 나눕니다. 층마다 커밋 여부와 수명이 다릅니다.

| 층 | 위치 | 커밋 | 내용 |
| --- | --- | :---: | --- |
| raw | 저장소 밖 | 안 함 | 기관에서 받은 원본 그대로 |
| processed | `data/processed/` | 안 함 | 정제·병합 중간 산출물 |
| marts | `data/marts/` | **함** | 노트가 직접 읽는 집계 파일 |

## 왜 marts만 커밋하는가

노트는 렌더링할 때마다 같은 결과를 내야 합니다. 노트 안에서 API를 호출하면
렌더링 시점에 따라 그림이 달라지고, 반년 뒤에 같은 노트를 다시 렌더링했을 때
무엇이 왜 바뀌었는지 알 수 없게 됩니다. 그래서 노트가 읽는 것은
`data/marts/` 에 커밋된 파일로 한정합니다.

raw는 용량이 크고, 기관의 이용 조건상 원본을 그대로 재배포하기 곤란한 경우도
있습니다. processed는 언제든 raw에서 다시 만들 수 있으므로 커밋할 이유가 없습니다.

## marts 파일 규칙

- 형식은 Parquet을 씁니다. 열 타입이 보존되고, 부분 읽기가 가능합니다.
- 이름은 `<소스>_<집계단위>_<범위>.parquet` 형태로 짓습니다.
  예: `airkorea_daily_sido.parquet`, `nier_water_monthly_basin.parquet`
- 파일 하나가 집계 단위 하나에 대응합니다. 여러 단위를 한 파일에 섞지 않습니다.
- 어떤 프로브나 수집기가 만들었는지는 해당 노트의 `requires` 필드에 적습니다.

## 갱신 주기 티어

소스마다 갱신 주기가 크게 다르므로 수집 계층은 주기별로 나뉩니다.

| 티어 | 주기 | 소스 |
| --- | --- | --- |
| hourly | 1시간 | 에어코리아, 기상청 AWS/ASOS 시간자료 |
| daily | 1일 | 기상청 일자료 |
| monthly | 월 1회 | 물환경 수질측정망 (확정값은 익년 초) |
| quarterly | 분기 | 해양환경측정망 |

같은 노트에서 서로 다른 티어의 데이터를 섞을 때는 낮은 쪽 주기에 맞춰
집계해야 합니다. 자세한 지연 특성은 [데이터 출처](../sources.qmd) 페이지를 보세요.
